## 🛠️ 이 파일, 도대체 어떻게 쓰는 건가요?

여러분이 어떤 모델을 만들려고 하는지 요구를 파악하고 그에 걸맞는 효과적인 프롬프트를 제안할 수 있도록, 모델의 사고 과정과 프롬프팅 가이드 문서를 여기에 담아두었어요.

### 1. 일반적인 웹앱 (ChatGPT, Gemini 등)에서 사용하기

가장 쉽고 대중적인 방법이에요!

- **방법**: 대화를 시작하기 전, 이 파일의 전체 내용을 복사해서 채팅창에 붙여넣으세요. 그리고 **"이 내용대로 나를 도와주는 프롬프트 엔지니어가 되어줘"**라고 말하면 끝입니다.
- **효과**: 이제 AI는 단순히 답만 하는 게 아니라, 여러분의 질문 의도를 파악하기 위해 역으로 질문을 던지거나, 최적의 프롬프트를 2~3개씩 제안해 주는 전문가 모드로 작동합니다.

### 2. CLI 도구 (Codex, Claude Code 등) & AI 코드 에디터 (Cursor, Antigravity 등)에서 사용하기

에이전트의 도움을 받을 수 있어요!

- Codex, Claude Code, 그리고 Antigravity와 같은 도구들은 우리가 가진 파일을 직접 수정해주고, skills 또는 mcp와 같은 외부 도구를 활용할 수 있게 해줘요.
- 이 Assistant 모델과 함께 대화하며, 어떤 프롬프트를 원하는지 구체화하고, 직접 모델에게 지시문 파일을 생성 및 수정하도록 지시해 보세요. 모델이 생성한 파일을 검토하고 피드백을 제공하며 더욱 좋은 프롬프트를 만들어 나갈 수 있어요.

### 3. 🌟 강력 추천: Context7(mcp)와 함께 쓰기

- **Context7**은, 지식 단절이 있어 과거 내용만 알고 있는 AI에게, 최신 개발 문서를 제공해 주는 mcp 서비스예요.
- 사용하고 있는 CLI/IDE에 Context7을 연결하여, 모델과 대화할 때 프롬프트에 "use context7"이라고 적어주시면, 모델이 알아서 최신 개발 문서를 읽고 정확한 답변을 제공해 줄 거예요.
